# Sora — Bespoke Wedding Rings by Kim キム

Exploring modern web experiences through thoughtful design, responsive interfaces, and luxury e-commerce aesthetics.

## ✦ Core Focus

- **Interface Design**: Minimalist, high-end editorial aesthetics focusing on balance, clarity, elegant typography, and intentional space.
- **Frontend Implementation**: Designing and implementing responsive e-commerce interfaces with modern frontend tools.
- **Creative Exploration**: Interactive experiments, smooth motion, and premium visual experiences exploring modern luxury on the web.

## 🛠 Development Process

This project was developed through an AI-assisted creative workflow, using AI as a tool for faster prototyping, exploration, and refinement.

AI supports the workflow, but the creative direction, design decisions, and final experience are guided by human intent.

My primary focus and contributions include:

- Defining UI and visual direction
- Making interface design decisions
- Customizing and refining components
- Implementing frontend interactions and smooth scrolling
- Optimizing responsive experiences
- Testing, refining, and deploying the project

## ⚙️ Tech Stack

- React
- Vite
- Tailwind CSS
- Motion
- TypeScript
